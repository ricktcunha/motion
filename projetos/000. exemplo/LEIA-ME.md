# Modelo de projeto

Copie esta pasta para `projetos/<NNN. nome>/` e preencha `plano.md`. O arquivo `exemplo-plano-jev.md` é um plano completo de referência; não o use como plano do novo vídeo.

- `video/`: master fornecido, sem alterar o arquivo original.
- `prints/`: referências enviadas pela pessoa.
- `frames/`: quadros de análise.
- `transcricao/`: transcrição com tempos.
- `assets/`: assets criados ou preparados para a composição.

Use `npm run project:new -- <slug> "<nome>"` para preparar as pastas locais e o plano de um trabalho novo. A composição só começa depois da aprovação do plano.
